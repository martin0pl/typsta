# typsta

A little tool to help you create new Typst project with a template.

There are definitely some errors and messy code. Please don't hesitate to report any mistakes you see.

## Short guide to best practices

- Each template must be a folder with the name of the template and this folder must be compose of a `main.typ` file and a `template.typ` file.
- The first line of the `template.typ` file must be `// <template_name>`.
